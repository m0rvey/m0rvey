### ⚡ Highlights & Focus

- 🔒 **Offline-First & Local-First:** Architecting systems with zero cloud lock-in, client-side indexing, and local data persistence (IndexedDB, SQLite WAL).
- 🧠 **On-Device AI:** Integrating local speech-to-text (Whisper/CoreML), quantized LLMs (Ollama), and real-time heuristics with zero telemetry.
- 🎯 **High-Performance Extensions:** Browser engineering with Chrome Manifest V3, Web Workers, and real-time DOM telemetry.
- 🍏 **macOS Ecosystem:** Crafting swift, lightweight desktop utilities with SwiftUI and Apple Silicon acceleration.

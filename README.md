### ⚡ Focus

- 🧠 **On-Device AI:** Local speech-to-text (Whisper via CoreML / DirectML), quantized LLMs and real-time heuristics — everything stays on the hardware.
- 🎙️ **UltraDictate:** Cross-platform push-to-talk dictation powered by the Apple Silicon Neural Engine (M1–M5, A18 Pro) and Windows DirectML GPU/NPU acceleration.
- 🍏 **Native Craft:** Lightweight desktop apps with Swift 6 and .NET 8, hardware-accelerated and human-friendly UX.
